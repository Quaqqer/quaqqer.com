## Controls

DPAD - Arrow keys \
B - Z \
A - X \
Start - Enter \
Select - Right Shift

F - Toggle Fullscreen

## Description

Nemu is my own
[NES](https://en.wikipedia.org/wiki/Nintendo_Entertainment_System) emulator
written in Rust.

Only a limited set of mappers are implemented. Different games require different
mappers. Some working games are "Donkey Kong", "Super Mario Bros", "Zelda" and
"Castlevania". Consult the links to find out more.

- [x] [Mapper 0](https://nesdir.github.io/mapper0.html)
- [x] [Mapper 1](https://nesdir.github.io/mapper1.html)
- [x] [Mapper 2](https://nesdir.github.io/mapper2.html)
- [x] [Mapper 3](https://nesdir.github.io/mapper3.html)
- [ ] [Mapper 4](https://nesdir.github.io/mapper4.html)
