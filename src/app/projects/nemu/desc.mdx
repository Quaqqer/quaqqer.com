Select a rom to start playing.

## Controls

DPAD - Arrow keys \
B - Z \
A - X \
Start - Enter \
Select - Right Shift

F - Toggle Fullscreen

## Description

Nemu is my own
[NES](https://en.wikipedia.org/wiki/Nintendo_Entertainment_System) emulator
written in Rust.
